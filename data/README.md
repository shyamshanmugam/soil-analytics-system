# Data

Do not commit raw or private farm data. The image dataset should contain labelled
soil classes such as Red Soil, Black Soil, Alluvial Soil, and Clay Soil. It does not
provide reliable N/P/K, pH, moisture, or organic-matter laboratory measurements.

Add real structured data later as a CSV matching the schema in the API. Any demo
records must be labelled synthetic/demo and must never be reported as measurements.
